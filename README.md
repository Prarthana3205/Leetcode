# DSA Questions Repository

A collection of Data Structure and Algorithm practice problems organized by difficulty level.

Each file contains:
- Problem statement (often with a LeetCode link)
- Complete solution implementation

## Repository Structure

```plaintext
DSAQs/
├── Easy/        - Basic level problems
├── Medium/      - Intermediate level problems
├── Hard/        - Advanced level problems
├── SQL/         - Database query problems
│   ├── Easy/
│   ├── Medium/
│   └── Hard/
└── README.md
```
## Languages Supported

- C
- Java
- Python
- SQL
